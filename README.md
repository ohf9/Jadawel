# جداول — محرر جداول بيانات (المرحلة 1)

تطبيق ويب تقدمي (PWA) يعمل في Chrome على Galaxy Tab S10+ وSamsung DeX واللابتوب، ويمكن تثبيته كتطبيق من قائمة Chrome ← "إضافة إلى الشاشة الرئيسية / تثبيت".

## لماذا PWA؟
- نسخة واحدة تعمل على Android والتابلت وDeX وWindows/Mac دون متجر.
- يعمل دون اتصال بعد أول فتح (service worker).
- يمكن لاحقًا تغليفه كتطبيق Android حقيقي (Trusted Web Activity) لتسجيله في "فتح بواسطة" في مدير الملفات.

## التشغيل
يحتاج خادم HTTPS (أو localhost). محليًا:
```
python3 -m http.server 8765 --directory docs
```
ثم افتح http://localhost:8765. للاستخدام على التابلت: ارفع مجلد `docs` إلى GitHub Pages أو أي استضافة HTTPS.

## ما تم في المرحلة 1 (ومختبر آليًا)
- فتح عدة ملفات XLSX/CSV معًا، تبويب لكل ملف، علامة • للملف غير المحفوظ.
- عرض ملفين جنبًا إلى جنب أو فوق بعض (للوضع العمودي)، مع فاصل قابل للسحب، وتحرير كل ملف مستقل (شريط صيغة ومربع اسم وأوراق لكل لوحة).
- نسخ/قص/لصق النطاقات بين الملفين (Ctrl+C/X/V والأزرار)، مع إزاحة المراجع النسبية في الصيغ كما في Excel، وتبادل النص مع التطبيقات الأخرى بصيغة Tab.
- سحب نطاق محدد من ملف وإفلاته في الآخر: بالماوس/القلم اسحب من داخل النطاق المحدد، وباللمس ضغطة مطوّلة على النطاق ثم اسحب. السحب ينسخ ولا ينقل.
- لمس: نقرة = تحديد، نقرتان = تحرير، ضغطة مطوّلة ثم سحب = تحديد نطاق.
- تراجع/إعادة لكل ملف، إضافة/إعادة تسمية/حذف أوراق، اتجاه الورقة يمين/يسار، أرقام عربية ٠-٩ تُفهم كأرقام، شريط حالة (مجموع/متوسط/عدد).
- حفظ تلقائي على الجهاز (IndexedDB) واستعادة كل الملفات والتعديلات بعد الإغلاق أو التعطل، وتنبيه عند الإغلاق بتعديلات غير محفوظة.
- الحفظ لا يستبدل الأصل دون موافقة: في المتصفحات التي تدعم الوصول للملفات يُسأل المستخدم "استبدال الأصلي / حفظ كنسخة"، والكتابة آمنة (ملف مؤقت ثم استبدال). وحيث لا يتوفر ذلك يُنزَّل الملف كنسخة جديدة.
- الحفظ بصيغة XLSX يفتح الملف الأصلي ويكتب الخلايا المعدلة فقط، فتبقى التنسيقات والصيغ والأوراق الأخرى.

## القيود الحالية (بصراحة)
- لا يوجد محرك حساب صيغ بعد (المرحلة 3): الصيغ تُقرأ وتُحفظ وExcel يعيد حسابها عند الفتح، لكن القيم المعروضة داخل التطبيق لا تتحدث بعد التعديل. تظهر شارة تحذير بذلك.
- التنسيق يُعرض جزئيًا فقط (غامق/مائل/لون/تعبئة/محاذاة/تنسيق أرقام بسيط)، ولا يمكن تعديله بعد (المرحلة 2). الخلايا المدمجة تُعرض كخلية عادية.
- XLS القديم غير مدعوم بعد (المرحلة 4). XLSM يُفتح لكن الماكرو لا يُحفظ.
- عند الحفظ بصيغة XLSX عبر مكتبة ExcelJS قد تُفقد الرسوم البيانية والجداول المحورية والأشكال الموجودة في الملف الأصلي. لذلك الحفظ الافتراضي لا يستبدل الأصل.
- النسخ واللصق بين الملفين ينقل القيم والصيغ وتنسيق الأرقام، وليس الألوان والخطوط.
- فتح الملفات من "فتح بواسطة" في مدير ملفات Android يتطلب تغليف التطبيق كتطبيق Android (لاحقًا)؛ حاليًا: زر فتح (اختيار عدة ملفات)، أو "مشاركة" الملفات إلى التطبيق بعد تثبيته، أو السحب والإفلات على اللابتوب.
- لم يُختبر بعد على جهاز Galaxy Tab S10+ فعلي (المرحلة 6)؛ الاختبار تم في Chromium بمقاس شاشة التابلت مع محاكاة اللمس.
